# 03 · 실시간 받아쓰기에서 글자는 언제 나타날까?

105번 화자의 녹음을 0.1초, 0.2초, 0.4초씩 보내면 ‘뭔’이 처음 보이는 시간은 각각 **1.40초, 1.40초, 1.60초**였다. 최종 문장은 세 번 모두 같았다. 이 숫자를 얻은 방법을 여섯 셀 순서대로 읽어 보자. [실습 노트북 열기](./03_streaming_asr.ipynb)

## 셀 1 · 녹음을 0.2초씩 읽기

```python
sr = sf.info(audio_file).samplerate
chunk_size = round(0.2 * sr)
received = 0
for chunk in sf.blocks(audio_file, blocksize=chunk_size, dtype="float32"):
    received += len(chunk)
```

- `audio_file`은 `~/.cache/asr-study/zeroth/105_003_0029.flac`이다. 파일을 읽으므로 마이크나 스피커 없이 실습할 수 있다. [Zeroth-Korean 낭독 자료 · CC BY 4.0](https://www.openslr.org/40/)
- `sr`은 16,000Hz다. 따라서 0.2초에 해당하는 `chunk_size`는 3,200개다.
- `sf.blocks`는 파일을 처음부터 한 조각씩 읽는다. `received`에 이번 조각의 **실제 길이**를 더하면 마지막 짧은 조각까지 정확히 셀 수 있다.
- `received / sr`는 지금까지 들어온 **녹음 속 시간**이다. 이 값으로 나온 시점은 발음의 정확한 시작 시각이나 컴퓨터의 연산 시간을 직접 측정한 값과 구분한다.

3,200개짜리 52조각을 보내면 10.40초다. 마지막에 856개가 더 들어와 **52 × 3,200 + 856 = 167,256개**, 즉 10.4535초가 된다. 출력은 소수 둘째 자리까지 **10.45초**다.

## 셀 2 · 스트리밍 인식기 만들기

`OnlineRecognizer.from_transducer(...)`는 네 파일을 읽어 `online`을 만든다. 실습에서는 `~/.cache/asr-study/streaming-zipformer-ko/` 아래 파일을 아래 이름으로 사용한다. [sherpa-onnx 공식 한국어 스트리밍 Zipformer 모델](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/online-transducer/zipformer-transducer-models.html#sherpa-onnx-streaming-zipformer-korean-2024-06-16-korean)

| 파일 | 맡은 일 |
|---|---|
| `encoder.int8.onnx` | 들어온 소리에서 발음에 쓰이는 특징을 읽는다. |
| `decoder.onnx` | 앞에서 고른 토큰을 바탕으로 다음 토큰을 고르는 데 필요한 정보를 만든다. |
| `joiner.int8.onnx` | 인코더와 디코더의 정보를 합쳐 이번에 낼 토큰의 점수를 계산한다. |
| `tokens.txt` | 토큰 번호에 해당하는 글자 또는 글자 묶음을 알려준다. |

## 셀 3 · 같은 스트림에 계속 쓰기

```python
def read_text(stream):
    while online.is_ready(stream):
        online.decode_stream(stream)
    return online.get_result(stream).strip()
```

1. `stream = online.create_stream()`은 녹음 한 편의 진행 상태를 담을 공간을 연다. 조각을 읽는 반복문 **앞**에 한 번만 만들어야 앞에서 들은 부분과 뒤에 들어오는 부분이 이어진다.
2. `stream.accept_waveform(sr, chunk * gain)`은 조각을 같은 스트림에 넣는다. 이 노트북의 `gain = 3.0`은 파형 값을 세 배로 곱하는 실험 설정이다.
3. `is_ready`는 지금 쌓인 소리로 다음 계산을 할 수 있는지 확인한다. 가능할 동안 `decode_stream`을 실행한다. `get_result`는 그 시점의 전체 문장을 돌려준다.
4. `if text != previous`는 문장이 바뀌었을 때만 시간과 문장을 출력한다. `previous = text`는 다음 조각과 비교할 문장을 기억한다.

예를 들어 0.2초씩 넣은 일곱 번째 조각에서 처음 ‘뭔’이 보였다. **7 × 3,200 ÷ 16,000 = 1.40초**다. 6.20초에는 문장이 ‘심각’으로 끝나고, 6.60초에는 ‘심각한 결과’까지 자랐다.

파일이 끝나면 0.66초의 무음을 덧붙여 끝소리를 처리할 여유를 주고 `input_finished()`로 마지막 입력임을 알린다. 실제 녹음 길이를 세는 `received`에는 이 무음을 더하지 않는다.

## 셀 4 · 조각 길이를 바꾸고 끝까지 비교하기

바깥쪽 반복문은 `[0.1, 0.2, 0.4]`에서 한 값을 골라 **새 스트림**을 만든다. 안쪽 반복문은 같은 녹음을 처음부터 끝까지 보낸다. `first_time is None and text`가 처음 참이 되면 시각을 딱 한 번 기록한다. 이후에도 조각을 계속 보내야 최종 문장까지 비교할 수 있다.

| 한 번에 보내는 길이 | 기본 조각의 샘플 수 | 전체 조각 수 | 첫 출력 |
|---|---:|---:|---|
| 0.1초 | 1,600 | 105 | 1.40초 · 뭔 |
| 0.2초 | 3,200 | 53 | 1.40초 · 뭔 |
| 0.4초 | 6,400 | 27 | 1.60초 · 뭔 |

세 조건에서 출력한 최종 문장은 마침표까지 같았다.

> 뭔 떡인지 못 받고 그냥 심각한 결과를 내렸습니다.

`final_texts[0.1] == final_texts[0.2] == final_texts[0.4]`의 결과는 `True`다. 이 비교는 같은 모델을 세 번 실행해 받은 최종 문자열이 같은지 검사한다. 원래 정답 문장은 ‘몬터규는 자녀들이…’로 시작하므로 정답과의 일치는 별도로 채점해야 한다.

## 셀 5 · 방금 붙은 글자만 찾기

```python
if current.startswith(previous):
    added = current[len(previous):]
```

`startswith`는 직전 문장이 지금 문장의 앞부분에 그대로 남았는지 묻는다. 그렇다면 `len(previous)`만큼 건너뛰고 뒷부분만 읽는다. ‘심각’에서 ‘심각한 결과’가 됐을 때 새 부분은 **‘한 결과’**다. 앞서 쓴 부분까지 바뀌면 `describe_change`는 이전 문장과 현재 문장을 ‘수정’으로 표시한다.

| 이번에 붙은 글자 묶음 | 0.1초씩 | 0.2초씩 | 0.4초씩 |
|---|---:|---:|---:|
| 뭔 | 1.40초 | 1.40초 | 1.60초 |
| 떡인지 | 1.70초 | 1.80초 | 2.00초 |
| 못 받고 | 4.60초 | 4.60초 | 4.80초 |
| 그냥 | 5.30초 | 5.40초 | 5.60초 |
| 심각 | 6.20초 | 6.20초 | 6.40초 |
| 한 결과 | 6.50초 | 6.60초 | 6.80초 |
| 를 | 8.80초 | 8.80초 | 8.80초 |
| 내렸습니다 | 9.10초 | 9.20초 | 9.20초 |
| 마침표 | 9.40초 | 9.40초 | 9.60초 |

‘떡인지’가 출력된 순간에는 세 글자가 함께 보였다. 이 기록으로 알 수 있는 시각은 **조각 하나를 보낸 뒤 프로그램이 글자 묶음을 처음 확인한 때**다.

## 셀 6 · 한글 막대그래프 읽기

`parts`의 글자 묶음과 `times_01`, `times_02`, `times_04`의 시각을 **같은 순서**로 적는다. 이 목록은 셀 5의 출력을 옮긴 값이다. 음성이나 볼륨을 바꾸어 실험하면 그래프에 쓸 시간 목록도 새 출력에 맞춰 바꾼다.

`ax.barh(y - h, …)`, `ax.barh(y, …)`, `ax.barh(y + h, …)`는 같은 묶음의 막대 세 개를 위·가운데·아래에 놓는다. 막대 길이는 경과한 녹음 길이이고, `bar_label`은 막대 끝에 그 값을 적는다.

**‘떡인지’ 행**에서 0.1초 조각은 1.70초에 확인할 수 있지만 0.4초 조각은 1.60초를 지나면 2.00초에야 다시 확인한다. **‘를’ 행**은 세 조건 모두 8.80초에 확인해서 막대 끝이 나란하다. 이 녹음에서는 조각을 잘게 보낸 덕분에 일부 중간 자막을 먼저 볼 수 있었고 최종 문장은 같았다.
